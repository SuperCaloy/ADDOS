# Project Knowledge Base

This `notes/` folder is the project's AI-maintained knowledge base, organized as an Obsidian vault.

## Structure

- `index.md` - Master index of all folders and topics
- `bugs/` - Bug reports, root cause analysis, and fixes
- `tasks/` - Implementation plans and task tracking

## Conventions

- Every note has YAML frontmatter with `created`, `last-updated`, and `status`
- Use `[[wikilinks]]` to cross-reference notes
- Use `> [!note]` callouts for important information
- Update `last-updated` whenever editing a note
- Mark notes as `status: draft` or `status: verified`
